Fluffy Robot Spacetraders Credit Report

Credit Reports

Fluffy Robot is a spacetraders.io api scraper and database. The main goal is to be able to see your credits and growth over the course of a reset and compare with others. Something that could be quickly checked when not at your dashboard like when you are waiting for the bus. Extra features like agent faction counts and jumpgate construction status came later.

The tool does not make an agent id, as such it is limited to non-authenticated endpoints. So while it can tell how many ships you have, it cannot see where they are or what kind it is.

Pick the account you want to view

There is no login — the dashboard reads SpaceTraders' public API and collects every agent it sees. The chart pages (credits, ships, jumpgate construction) only show the agents you have selected. These selections are stored in your browser local storage so it will carry on from week to week. There is a 'Clear Selection' button in preferences to reset that.

To pick your accounts to watch, use the Agents or Preferences pages: click an agent to select or deselect it. Your selections are saved in your browser and apply to every chart page. You can also mark one agent as your own in Preferences — It currently does not do anything. If a chart looks empty, try adding an agent from the leaderboard so you know there is someone that should have data.

How data updates

The collector polls the SpaceTraders API on fixed cycles:

  • Agents — every 5 minutes: credit and ship counts, leaderboards, and server stats. New agents appear on the next cycle.
  • Jumpgate construction progress — every 30 minutes, for systems that have already started building a jumpgate.
  • New construction scan — every 4 hours. The collector only checks systems that are the headquarters system of a collected agent and have not started construction yet; once it finds materials delivered there, that system moves to the 30-minute track. A jumpgate that just started building can therefore take up to 4 hours to show up.
  • Supply chain — static game data, fetched once.

Construction scan is the most expensive call, so it not done on every agent. It also does not tie to a specific agent, rather the home system for that agent. All the construction gates are checked every 4 hours, and if one is found that has some activity it is added to a list that gets updated every 30 mins.

The game resets weekly on Sunday around 13:00 UTC: leaderboards and jumpgate construction start fresh, and roughly four weeks of history is kept.

Caveats and Known Issues

Mobile friendly

  • The site is Mobile friendly, but not optimized for mobile.
  • Phone does work, but some of the busier charts are difficult to navigate.
  • Wide tables and charts scroll sideways inside their cards, not with the page.
  • The supply chain tree supports drag-to-pan and zoom — on a touch screen, dragging inside the chart moves the chart instead of scrolling the page. Scroll outside the chart, or tap a node to collapse a branch.

Resets

  • Currently only data in the current reset is shown. Future versions hope to have ability to go back in history
  • Data is held for four weeks, but the frontend doesn't know how to get it yet.
